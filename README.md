# Skills

## Skills

| Skill | What it does |
|---|---|
| [before-you-build](skills/before-you-build/) | Checks a product idea before anyone builds it. A short guided conversation that ends with a one-page card: test first, ship a small version, stop, or go back to the problem. |
| [to-the-point](skills/to-the-point/) | Turns a rough product idea and scattered notes into a coherent concept through conversation. Preserves your decisions and keeps the first version simple. |

Each skill has its own folder in `skills/`. Everything about a skill is in that folder: the skill itself, a README on how to install and use it, and its tests.

## Quick install

With [skills.sh](https://skills.sh) (needs [Node.js](https://nodejs.org)):

```bash
npx skills@latest add lukeblonski/skills
```

The installer asks which skills you want. Other ways to install, including the Claude app, are in each skill's README.
