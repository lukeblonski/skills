# Saved search for recruiters

**User:** in-house recruiters at mid-size companies (50-500 employees) using our ATS.
**Problem:** recruiters re-run the same candidate searches with the same 6-8 filters several times a day and rebuild the filters each time.
**Success metric:** median time from opening candidate search to first candidate opened, currently 95 seconds, target under 40 seconds.
**Scope:** save a filter set with a name; list of saved searches in the sidebar; one-click run. No sharing between users in v1.
**Rollout:** behind a flag to 30 recruiters for two weeks, then general availability.
